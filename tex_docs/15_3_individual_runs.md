# Task 15.3 — Individual Timed Dry-Runs

- **Status:** pending
- **Owner:** Brian, Helena (separately)
- **Duration:** 30 min + 30 min per author, twice each = 2 hours
- **Stage:** [VII](../stages/stage_VII_presentation.md)

## Goal

Each author delivers their 25-min talk alone, timed, at least twice. Blackboard talks run long on first delivery; we budget accordingly.

## Protocol

1. Find a chalkboard or whiteboard (practice room, empty classroom, bathroom mirror with dry-erase markers).
2. Start a visible timer.
3. Deliver the talk out loud.
4. Note where you ran over, where you got stuck, where the board got crowded.
5. Revise the script and try again.

## Targets

- First run: expect 32–35 min for a 25-min target.
- Second run: 26–28 min.
- If still over by > 2 min on second run, cut content.

## Acceptance criteria

- Each author has done at least two timed runs.
- Runs are within ±2 min of target.
