## Goal

State explicitly which FQH platforms are experimentally established and which are more tentative. This is a required "honesty box" from outline v2.

## Content

The honesty box should state:

1. **Abelian anyons** (Laughlin states $\nu = 1/3, 1/5$; Jain states $\nu = 2/5, 3/7$) have been observed with braiding statistics measured directly (Nakamura 2020, Werkmeister 2024; see Chapter 12).
2. **Non-abelian anyons** (claims for $\nu = 5/2$ Moore–Read state, Majorana zero modes in semiconductor-superconductor heterostructures, twisted bilayer graphene) are not yet unambiguously confirmed. Specific claimed Majorana sightings have been retracted or contested.
3. **Quantum processor emulations** (Andersen 2023) implement the braid-group algebra on hardware, but this is a synthetic realization, not a natural phase of matter.

## Tone

Matter-of-fact, not hedging. The honesty is the point.

- All three classes of platforms addressed.

## Risks
