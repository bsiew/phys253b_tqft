## Goal

Show that twisted Dijkgraaf–Witten theory with nontrivial $\alpha \in H^d(BG, U(1))$ provides a clean example of anomaly inflow: the bulk theory on $M$ is invariant, but its boundary theory on $\partial M$ carries a 't Hooft anomaly captured by $\alpha$.

## Content

1. Set up: $M$ with boundary. The bulk DW action $\int_M \alpha$ is only defined up to $\delta \alpha = 0$, but on a manifold with boundary the cocycle $\alpha$ restricted to $\partial M$ is well-defined only modulo exact pieces.
2. The boundary theory has a 2-cocycle anomaly inherited from the 3-cocycle bulk $\alpha$. Specifically, gauging the bulk $G$-symmetry requires the boundary partition function to shift by a local functional, which is the anomaly.
3. Concrete example: $G = \mathbb{Z}_2$, twist $\omega_1 \in H^3(\mathbb{Z}_2, U(1))$. The 2D boundary theory has an anomaly detectable by the mod-2 mapping class group invariance of the partition function.
4. Connect to Chapter 8: this is the same inflow mechanism that the chiral fermion anomaly uses.
