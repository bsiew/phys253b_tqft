## Goal

Condensed-matter-side anomaly inflow: the edge chiral fermion of a 3D topological insulator has a mixed $U(1)_{\text{charge}} \times T$ anomaly that is canceled by the bulk $\theta$-term at $\theta = \pi$. Balance the 5D CS example of §8.6 with this CM counterpart.

## Content

1. **Setup.** 3D topological insulator with time reversal $T$; its 2D edge has a single Dirac cone (or a protected chiral mode under specific boundary conditions).
2. **Edge anomaly.** The edge fermion has a mixed $U(1) \times T$ anomaly making the edge state impossible to realize in 2D alone.
3. **Bulk θ-term.** The bulk has a $\theta$-angle for electromagnetism: $S_\theta = (\theta / 32\pi^2) \int F \wedge F$. For $T$-invariance we need $\theta = 0 \mod 2\pi$; a topological insulator has $\theta = \pi$ which is $T$-invariant mod gauge transformations.
4. **Inflow.** Under a background gauge transformation that would anomalously shift the edge, the bulk $\theta = \pi$ term picks up compensating boundary shift.
5. **Direct parallel to §8.6.** The bulk 4D $\theta$-term is the same kind of invertible TQFT as the 5D CS; one flavor of inflow.
