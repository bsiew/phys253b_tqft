# Task 18.4 — Joint Dry-Run with Handoff

- **Status:** pending
- **Owner:** Brian + Helena
- **Duration:** 75 min (60 min + Q&A practice)
- **Stage:** [VII](../stages/stage_VII_presentation.md)

## Goal

Full 50-minute run with both authors, in presentation order, with board layout exactly as planned. Plus 10-min Q&A simulation.

## Calendar constraint

This cannot wait until the literal final day. Put it on the calendar no later than Day 7, and run it no later than Day 8 morning.

## Protocol

1. Same room as the real presentation if possible.
2. Brian delivers 25 min → stops.
3. 30-second transition for Helena to erase and set up her portion of the board.
4. Helena delivers 25 min.
5. 10-min Q&A: Brian's partner (or a friend) asks the three hardest prepared questions, plus one surprise.

## Critical checks

- Does the board layout actually work? (Often discovered that equations we planned to keep up get in the way.)
- Does Helena's opening line land given Brian's closing line?
- Is Brian's CS action still legible when Helena cites it at her minute 3?

## Acceptance criteria

- Full run completes.
- Board layout viable.
- Q&A handled without visible panic.
- Feedback note written in `plan/presentation/joint_run_notes.md` with what needs fixing for the real talk.

## Risks

- **Scheduling.** Get this on calendar early; if it slips to the final evening, the plan is already in trouble.
